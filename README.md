# Кураторские списки Text Autofix

Public-репозиторий для плагина **Text Autofix** (Циан).

Здесь два редакционных списка, которые плагин подтягивает с GitHub при запуске.  
Пересобирать плагин после правок **не нужно** — достаточно сохранить файл в ветку `main`.

| Файл | Что делает плагин |
|---|---|
| [`ty-vy-curated.txt`](./ty-vy-curated.txt) | Автозамена обращения «ты» → «вы» (кнопки, формы, ЛК) |
| [`yo-curated.txt`](./yo-curated.txt) | Автозамена «е» → «ё», где ё **обязательна** |

Омонимы вроде **все / всё**, где оба варианта допустимы и нужен выбор человека — **не здесь**.  
Они в [text-autofix-word-forms](https://github.com/butsena/text-autofix-word-forms) (блок «Выберите вариант»).

---

## Как править (общий порядок)

1. Откройте нужный файл по ссылке в таблице выше.
2. Нажмите карандаш (**Edit this file**).
3. Внесите правку по формату ниже.
4. **Commit changes** → в ветку `main`.

Если нет доступа на запись — оформите Pull Request в `main`.

Через несколько минут (или после Reload плагина) обновление подхватится само.

## `ty-vy-curated.txt` — ты → вы

### Зачем

В интерфейсе Циана к пользователю обращаемся на **вы**.  
Плагин автоматически меняет формы «ты» на «вы» по этому словарю (кнопки, поля, подсказки).

### Формат

Одна замена на строку:

```txt
исходная_форма,верная_форма
```

Несколько исходников с одной целью — исходники в кавычках через запятую:

```txt
"форма1, форма2",верная_форма
```

Примеры:

```txt
# Повелительное наклонение (кнопки, CTA)
нажми,нажмите
Нажми,Нажмите
заполни,заполните

# Несколько вариантов одной цели
"глянь, гляньте",посмотрите
```

### Правила

1. Регистр важен: обычно нужны **обе** строки — со строчной и с заглавной (`нажми` / `Нажми`).
2. Пустые строки и строки, начинающиеся с `#`, — комментарии, плагин их пропускает.
3. Не ставьте пробелы вокруг запятой между колонками (`нажми,нажмите`, не `нажми, нажмите`).
4. Не меняйте имя файла.
5. Сюда **не** кладём местоимения вроде «ты/вы» в середине предложения, если для них уже есть отдельные правила в плагине — этот файл про **глаголы и формы CTA**.

### Как проверить

В Figma: слой с текстом вроде «Заполни твой профиль» → после проверки должно стать «Заполните ваш профиль» (часть замен из этого файла + связанные правила).

## `yo-curated.txt` — обязательное ё

### Зачем

Список словоформ, где по редполитике Циана пишем **ё**, а не «е».  
Плагин сам заменяет: `еще` → `ещё`, `отчет` → `отчёт` и т.п.

Сюда попадают только случаи, где «е» вместо «ё» — **ошибка**, а не равноправный вариант.

### Формат

Одна форма **с буквой ё** на строку:

```txt
ещё
отчёт
платёж
отчёта
отчётный
```

### Правила

1. Пишите уже **правильную** форму с `ё` / `Ё`. Плагин сам строит пару «е → ё».
2. Нужны нужные словоформы (не только именительный): `отчёт`, `отчёта`, `отчётный`…
3. Не добавляйте слова, где «е» и «ё» — **разный смысл** или оба допустимы (например все/всё) — это [word-forms](https://github.com/butsena/text-autofix-word-forms).
4. Не добавляйте слова вроде «оплачен / оформлен», где «е» нормальна.
5. Пустые строки и `#`-комментарии допустимы, но в текущем файле обычно просто список форм.
6. Не меняйте имя файла.

### Как проверить

Слой с текстом «еще раз смотрите отчет» → плагин должен предложить/применить «ещё» и «отчёт».

## Для разработчиков плагина

Перед Community-релизом синхронизируйте remote → бандл в репозитории плагина:

```bash
npm run sync:curated-lists
npm run build
```

Подробности: `docs/curated-lists-github.md` в репозитории плагина.
